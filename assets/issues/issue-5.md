# Issue [#5](https://github.com/thanhnguyen-agilityio/claude-training-practice/issues/5)
## Title: No way to start a new conversation or clear chat history
## Description:

**Issue**
- Once a user starts a conversation, there is no clear way to start a fresh conversation.
- Users cannot clear the current chat and begin with a clean slate.
- The only way to start over is to manually change or clear the Thread ID, which is not intuitive.
- This is confusing when users want to ask about a completely different topic or when they want to clean up a long conversation.

**Expected**
- There should be a clear "New Chat" or "Start New Conversation" button visible in the interface.
- When clicked, it should clear the current conversation and start fresh (similar to ChatGPT, Claude, or other chat applications).
- Optionally, save the previous conversation in a sidebar so users can return to it later.
- The button should be easy to find, perhaps in the sidebar or at the top of the chat area.

**User Impact**
- Users get frustrated when conversations become too long and cluttered.
- Users want to change topics but don't know how to start fresh without losing their place.
- This is a standard feature in most modern chat applications that users expect.
